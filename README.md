# Paradise Nursery Shopping Application

A React-based e-commerce application for an online plant shop. 

## Features
* **Landing Page:** Welcomes users with a background image and a "Get Started" button.
* **Product Listing:** Displays a dynamically rendered list of 18 unique houseplants categorized into 3 different groups. Allows users to add items to their cart.
* **Shopping Cart:** Built with Redux Toolkit to manage state. Users can increment, decrement, or remove items, view per-item totals, and see the overall cart total.
